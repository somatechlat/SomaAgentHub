# Accessibility Statement (WCAG2.1 AA)

![Version](https://img.shields.io/badge/version-1.0.0-blue)

We commit to:
- **Perceivable** – all images have descriptive `alt` text; colour contrast ≥4.5:1.
- **Operable** – full keyboard navigation; skip‑to‑content links on every page.
- **Understandable** – plain‑language writing; glossary for technical terms.
- **Robust** – valid HTML5 generated by MkDocs‑Material.

Automated checks (`axe-core`) run on every CI build; failures block the merge.

## SomaAgentHub Accessibility Features
- All service diagrams include text descriptions
- Code examples have clear context and explanations
- Technical terms are defined in the glossary
- Navigation structure supports screen readers
