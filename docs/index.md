SomaAgentHub documentation is organized into four core manuals, each serving distinct audiences and use cases:

- **Installation & Setup** - Access the platform and configure client tools
- **Core Features** - Multi-agent orchestration, workflows, and governance
- **Use Cases** - Real-world applications and business scenarios
- **Troubleshooting** - Common issues and solutions

### 🔧 [Technical Manual](technical-manual/index.md)
**For system administrators, SREs, and DevOps teams**

Master the deployment, operation, and management of SomaAgentHub in production environments.

- **Architecture** - System design and component interactions
- **Deployment** - Installation, configuration, and scaling
- **Monitoring** - Observability, metrics, and alerting
- **Security** - Access control, compliance, and hardening
- **Runbooks** - Operational procedures and incident response

### 💻 [Development Manual](development-manual/index.md)
**For software engineers and contributors**

Understand how to build, modify, and contribute to the SomaAgentHub codebase.

- **Local Setup** - Development environment configuration
- **Coding Standards** - Style guides and best practices
- **Testing** - Unit, integration, and end-to-end testing
- **API Reference** - Complete API documentation
- **Contribution Process** - Git workflow and pull request guidelines

### 🚀 [Onboarding Manual](onboarding-manual/index.md)
**For new team members, contractors, and agent coders**

Get up to speed quickly on SomaAgentHub's architecture, development practices, and team culture.

- **Project Context** - Mission, goals, and business understanding
- **Environment Setup** - Complete development environment configuration
- **Codebase Walkthrough** - Architecture and code organization

- **Team Collaboration** - Communication patterns and workflows
